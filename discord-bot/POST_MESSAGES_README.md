# 自動發布 Discord 歡迎訊息

## 🎯 功能

這個腳本會自動：
1. 在所有頻道發送歡迎訊息
2. 自動釘選這些訊息
3. 完成後自動關閉

## 🚀 使用方式

### 執行腳本

```bash
cd discord-bot
node post-welcome-messages.js
```

### 執行後

Bot 會自動：
- ✅ 找到所有頻道
- ✅ 發送對應的歡迎訊息
- ✅ 自動釘選訊息
- ✅ 顯示執行進度
- ✅ 完成後自動關閉

## ⚠️ 注意事項

1. **執行前確認 Bot 有權限：**
   - 發送訊息
   - 釘選訊息（Manage Messages）

2. **會員專區頻道需手動處理：**
   - 🥈-LINE會員
   - 🥇-店內消費者
   - 💎-貼圖收藏家
   - 🌟-超級粉絲
   
   這些頻道有權限限制，建議手動複製貼上

3. **避免重複執行：**
   - 每個頻道會被釘選訊息
   - 重複執行會產生多個釘選

## 🔧 如果需要修改訊息

編輯 `post-welcome-messages.js`
找到 `CHANNEL_MESSAGES` 物件
修改對應頻道的內容
