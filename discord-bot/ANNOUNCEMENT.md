## 🚀 快速開始 3 步驟

### Step 1: 完成測驗
前往 **https://kiwimu-mbti.vercel.app** 完成你的性格測驗

### Step 2: 獲得身份組
測驗完成後，在這裡輸入：
```

```

> 測驗結果頁面 → 點擊右上角「我的檔案」→ 複製 User ID
