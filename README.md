# Kiwimu MBTI Lab v5

## Project Status
This project uses:
- **Frontend**: React + Vite
- **Styling**: TailwindCSS
- **Authentication**: Firebase Auth (Google & LINE)
- **Deployment**: Vercel

## Deployment
Latest update: LINE Login integration.

## Setup
1. Clone repository
2. `npm install`
3. `npm run dev`

## Environment Variables
Required for deployment:
- `VITE_LINE_CHANNEL_ID`
- `VITE_LINE_REDIRECT_URI`
- `LINE_CHANNEL_ID`
- `LINE_CHANNEL_SECRET`
- `LINE_REDIRECT_URI`
- `FIREBASE_SERVICE_ACCOUNT`
