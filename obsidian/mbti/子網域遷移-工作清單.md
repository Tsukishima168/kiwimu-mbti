## 每個子專案的遷移步驟

### Step 1：Vercel 設定子網域

1. 進入子專案的 Vercel Dashboard
2. **Settings** → **Domains** → **Add Domain**
3. 輸入子網域（例如 `map.kiwimu.com`）
4. 到 DNS（Cloudflare / Namecheap / etc）新增 CNAME：
   ```
   CNAME  map  cname.vercel-dns.com
   ```
5. 等待 SSL 憑證生效（通常 < 5 分鐘）

### Step 2：更新主站（MBTI）的跨站連結

需要修改的檔案與內容：

```bash
# 搜尋所有舊的 Vercel URL
grep -rn "vercel.app" --include="*.tsx" --include="*.ts"
```

- `.env` 更新 redirect URI
- LINE Developers Console 更新 Callback URL
- Google Cloud Console 加入新的子網域
- Firebase 授權域名加入新的子網域
