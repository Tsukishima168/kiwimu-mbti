## ⏳ 待操作（需人工執行）

### Vercel 設定子網域（每個專案都要做）

1. 進入子專案的 Vercel Dashboard
2. **Settings** → **Domains** → **Add Domain**
3. 輸入子網域
4. 到 DNS（Cloudflare）新增 CNAME：
   ```
   CNAME  map      cname.vercel-dns.com
   CNAME  shop     cname.vercel-dns.com
   CNAME  passport cname.vercel-dns.com
   CNAME  gacha    cname.vercel-dns.com
   ```
5. 等待 SSL 憑證生效（通常 < 5 分鐘）

### OAuth 更新（有登入功能的子站）

參照 [[網域遷移-SOP-kiwimu-com]] 依序操作：
- Supabase → **Auth** → **URL Configuration** → Allowed Redirect URLs 加入 `https://*.kiwimu.com/**`
- Google Cloud Console → 加入各子網域的 Authorized Origins + Redirect URIs
- LINE Developers → Callback URL 更新（如有用 LINE Login 的子站）
- Firebase Console → Authentication → Authorized Domains 加入各子網域
