## 一句話定位

> V2 的報告是 YZ 世代版的「好朋友說中你此刻的狀態」，不是心理學教科書的翻譯版，也不是散文詩。

## 1. 聲音（Voice）

### 說話的人是誰

一個**很懂你、正在看著你、不會說教的朋友**。

- 不是諮商師（不引導、不解釋過多）
- 不是演算法（不冷、不通用）
- 不是詩人（不抒情、不隱喻）
- 是那種一句話讓你「靠，你怎麼知道」的人

### 語氣關鍵字

```
直接   觀察式   精準   不閃躲   有呼吸   此刻在場
```

> 注意：不是「帶點刺」。刺容易滑向毒舌或嘲諷。
> 「不閃躲」的意思是：說真的，不繞，不軟化，但也不刻薄。

### 不要的語氣

```
永恆定型   抒情散文   學術腔   正能量喊話   溫柔過頭的糊
```

### 時態原則（最關鍵）

V2 是**狀態報告**，不是**類型描述**。時態決定一切。

| ❌ 類型時態（永恆） | ✅ 狀態時態（當下） |
|---|---|
| 你是一個... | 你現在是... |
| 你總是... | 你最近... |
| 你從小就... | 這陣子你... |
| 你的本質是... | 你此刻的運作方式是... |
| INTJ-A 的人會... | 你在這個階段會... |

類型報告說的是「你」，狀態報告說的是「你現在」。
一個字的差別，整個產品的位移。

## 2. 痛點打擊公式

YZ 世代不需要被「告知」他們是什麼，他們需要被「說中」。
每個段落的底層結構：

```
1. 觀察：說出他們此刻感受過但沒被說出來的東西
2. 命名：幫這個感覺一個名字（讓模糊變清晰）
3. 翻轉：不是問題，是你現在的運作方式
```

### 三步範例（狀態版）

**觀察**
> 你最近常常想說什麼，但話到嘴邊就停下來。

**命名**
> 這不是表達卡關，是你在校準。

**翻轉**
> 你不想輸出一個還沒長好的版本——
> 所以你選擇先不說。

這三步在一段話裡完成，不用分開。但寫的時候要知道自己在做哪一步。

## 3. DOES 作為隱形寫作引擎

使用者看不到 D / O / E / S 這四個字。
寫手用它來定位：這個 type 的痛點在哪個維度、這段話該怎麼進入。

### D — 句子要有第二層

高 D 的人會把一句話讀兩遍。不要寫平。

```
寫法：表層是觀察，底層是機制
第一眼讓他覺得「對，我是這樣」
第二眼讓他想「為什麼我是這樣」
```

**檢查問題**：這句話除了共鳴，還有沒有一個值得想的點？

### O — 一次只給一件事

高 O 的人容易被塞滿。一段話只打一個主張。

```
寫法：每個段落只有一個觀察
段落之間有呼吸（視覺留白 + 語氣落點）
不要在同一段塞兩個不同層級的見解
```

**檢查問題**：這段話是不是藏了兩件事？如果是，拆開。

### E — 情緒先落地

高 E 的人**感覺比語言快**。不要先給分析，情緒會接不住。

```
寫法：第一句話是感受命名，不是分析
讓他先感受到「被看到」
再進入「為什麼」
```

**檢查問題**：第一句話讀完，是「我感覺被懂了」還是「我在上課」？

### S — 用字要準，不能漂亮但空

高 S 的人會注意到字。不準確的字會讓他產生距離。

```
寫法：用具體情境 > 抽象形容詞
用讓人停下來的精準字 > 詩意的飄字
不是「你很敏感」，是「你注意到的是那個語氣微變」
```

**檢查問題**：這個字，換一個更準的，會不會比較像他？

### 範例 2｜Protective Pattern 主段（INTJ-A）

❌ **舊 V2 寫法**

✅ **V2 寫法**

```
❌ 內向者 / 外向者（當作身份標籤使用時）
```

### 心靈雞湯詞

## 8. 三條死規則

違反這三條，整段重寫。

```
1. 不在報告正文出現任何理論名字、學派、學者名稱
2. 不用永恆時態描述狀態（「你一直…」「你從小…」）
3. 不給命令式行動建議（「你應該…」「試著…」「你需要…」）
```

> 規則 3 的例外：
> ✅ 開放式提問可以（「如果今天有人真的裝得下你說的，你會先說什麼？」）
> ✅ 帶空間的 reflection 可以（「你最在乎的那個版本，有沒有人見過？」）
> ❌ 行為矯正不可以（「建議你練習說出來」「試著讓人更靠近你」）

## 11. 寫作檢查清單

寫完一段後，對自己問這四題：

```
□ 時態對嗎？（狀態式，不是永恆定型）
□ 第一句有沒有命中感受？（E 先落地）
□ 有沒有塞兩件事在同一段？（O 要拆開）
□ 用字夠準嗎？（S 要精準，不是漂亮）
```

四題都是 ✓，才算過。
