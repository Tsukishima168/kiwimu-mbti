# V2 Funnel + Product Strategy

> Status: v2 — 現行商品與會員回訪校正
> Last updated: 2026-10-05
> Penso 指定五站主目標：會員回訪與集章。跨站控制契約見 Obsidian 既有五站 UPGRADE_SPEC.md v2。

## 1. 正式商品與版本分工

| 產品 | 正式入口 | 角色與權益 |
|---|---|---|
| V1 | `/` | 免費 MBTI 測驗；既有登入、測驗紀錄與 archive |
| V1.5 | `/explore` | 獨立快速探索與分享；不是 V2 的前置關卡 |
| V2 | `/read`、`/read/quiz`、`/read/{TYPE}-{A|T}` | 免費試讀第01章，NT$99 解鎖所購型別的02–08章 |
| 我的報告 | `/read/library` | 登入後讀取帳號已保存的購買資格，繼續閱讀 |

**NT$99 = 解鎖所購型別的完整 V2 MBTI 深度報告。**

付款或登入不代表所有型別都解鎖。匿名購買需在原裝置登入後明確保存到帳號；跨裝置重看由伺服器驗證該帳號資格。HttpOnly cookie、訂單驗證與 server report API 保留，不把全文放回 client bundle。

## 2. 五站聯動

V1/V1.5/V2 完成後提供「回護照看今日任務」。Passport 是會員回訪入口，使用者可選在家線上任務或到店 GPS/QR。Passport 另提供 `/read/library` 回看入口，讀完報告可以再回護照。

- 主入口使用 `screen=passport&tab=hub&from=mbti_<位置>`。
- 沿用原有有效 claim 路徑；一般回訪連結不增加 auto_unlock、stamp 或點數參數。
- 內部連結不用 UTM 重寫外部廣告來源。from 表示入口，不能当付款、已集章或已核銷證明。
- 味覺配對屬品牌敘事；實際商品、價格、供應以月島菜單為準。甜點預訂是可選下一步。
- 回護照不等於自動保存已購報告，也不宣稱同步本機遊戲點數成可兌換餘額。

## 3. 首次與回訪

首次：免費試讀 → 清楚展示02–08章內容與NT$99 → 登入／付款 → 保存至帳號 → 繼續閱讀。

回訪：我的報告 → 伺服器確認已購型別 → 使用者選擇繼續閱讀 → 回護照查看任務。閱讀位置依帳號與型別保存在裝置，保留180天；不是180天付費權益期限，也不是跨裝置閱讀位置同步。

避免每次回訪都重測、重買。一般使用者仍可直接免費探索，不強迫付費才成為會員。

## 4. 尚未提供的 V3 構想

90天變化敘事、跨次比較、狀態報告、個人timeline成長摘要均未列為目前NT$99權益。若後續要做，先定資料來源、比較規則、期限與價格，再實作與驗收；不能先把未來功能寫進商品承諾。

## 5. 驗收與經營

- 版本入口／已購library／回護照連結可用，內部無UTM、無個資或付款憑證。
- 鎖定與解鎖繼續由server決定，訪客／其他帳號不能靠網址免費解鎖。
- 先看會員7日回訪與已購重讀，再看V2成交；實際集章、兌換只以權威ledger計算。
- 新NT$99真人付款、通知、iPhone跨站/跨裝置仍依獨立證據簽收；build通過不等於這些真人流程完成。
