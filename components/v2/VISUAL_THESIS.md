## 0. Thesis（一句話）

> **One character, many states. 角色是錨，狀態是風。**

V1 講「你是誰」（type）。
V2 講「你此刻如何」（state）。

Type 是名詞，State 是副詞。
報告的主詞（角色）不變，描述它的方式（氛圍）會變。

---

## 1. 為什麼這條路

| 階段 | 語言 | 感覺 |
|---|---|---|
| V1 | 安靜 | 圖鑑式，角色站著等你看 |
| V1.5 | 跳躍 | 角色動起來，資訊密集 |
| V2 | **流動** | 角色安靜站著，環境在呼吸 |

V2 不是更極簡、也不是更花俏。是**讓視覺會呼吸**——因為狀態本身就是會變的東西。

對 YZ 世代：
- 不買「我是 INTJ」這種固定標籤
- 買「我現在在我的 X era」這種此刻敘事
- 截圖分享時，別人看得出「這是 Kiwimu」而不是「這是某個 MBTI 站」

視覺護城河來自 **「別人看一眼就知道這是你」的辨識文法**，不是好看。

## 2. 狀態座標系（State Coordinate System）

V2 的狀態不是離散分類，是**三軸連續座標**。使用者測出來落在三維空間的某個點，插畫/氛圍系統依座標渲染。

### 三軸

| 軸 | 一端 | 另一端 | 視覺對應 |
|---|---|---|---|
| **能量** (Energy) | 高亢 / 外放 | 沉靜 / 內收 | 粒子密度、動態速度 |
| **焦點** (Focus) | 聚焦 / 銳利 | 擴散 / 朦朧 | 景深、邊緣銳利度、光線收束 |
| **色溫** (Warmth) | 暖 / 溫柔 | 冷 / 清明 | 主色相、光源顏色 |

三軸不直接對應 MBTI 的 E/I、S/N、T/F、J/P，而是**從四維壓縮成三維感受**。這樣才跳出 type 思維，真正講 state。

> **映射規則待定**。會需要一個 function：`(mbti4letters, A/T) → (energy, focus, warmth)`。這是下一份文件（DESIGN.md 或獨立的 state-mapping.md）要處理的。

### 為什麼是三軸不是四軸

三軸對應視覺最直覺的三件事：**速度、清晰度、溫度**。四軸開始抽象，使用者看不出差別。

## 3. Visual Grammar（視覺文法）

這是 V2 獨有的語法。別的站抄不走，因為是你的。

### 3.1 角色層（不變的錨）

- **每個 variant（32 個）有一個固定基礎形**
- 角色**姿態不變**（站著、半身、統一構圖）
- 角色**線條/輪廓固定**，視覺記憶點來自這裡
- 32 張基礎形 = V2 的 IP 資產

✅ Do：角色永遠在畫面同一個位置（建議中央偏下或黃金比例點）
❌ Don't：不要為「狀態」改變角色本體，狀態不住在角色身上

### 3.2 環境層（會變的風）

狀態**不在角色身上**，在角色**周圍**。

環境層由四種元件組成：

| 元件 | 負責的軸 | 實作方式 |
|---|---|---|
| **色溫漸層** | 色溫軸 | 背景 radial / linear gradient，兩個主色由座標決定 |
| **粒子/氛圍** | 能量軸 | 浮動光點、微粒、線條。密度與速度 = 能量值 |
| **光線品質** | 焦點軸 | 主光源方向固定（上方或左上），邊緣 blur 量 = 焦點反向 |
| **節奏** | 能量 × 色溫 | 微動態循環時間（慢呼吸 vs 快脈動） |

✅ Do：環境層用 CSS + SVG + 輕量 motion，不用影片、不用重 Lottie
❌ Don't：不要把環境做成裝飾背景，它是主要敘事元件

### 3.3 文字層（旁白，不是主角）

這是你說「文字跟排版不喜歡」那層的重寫。

當角色 + 環境變成主敘事，文字應該：

- **退到旁白位置**（editorial 雜誌感，不是資訊卡密度）
- **大留白**，一頁少於三種字級
- **serif 中文 or semi-condensed sans** 處理標題，讓它有出版物感而不是 app 感
- **內文 14–15px、leading 1.8**，不是現在的資訊卡 12–13px 擠壓感
- 每個段落像一句 pull quote，不像一個欄位

參考氣質：Co—Star、Dazed、Apple Newsroom。**不是** Notion、16Personalities。

### 3.4 版面層（頁面作為一首詩）

V2 報告從「資訊頁」重構成「章節頁」。

- 一個 section = 一個螢幕高度（vh-based）
- scroll = 翻頁感，不是捲資訊
- 每個 section 有 **一個主元件**（角色 / 一句話 / 一張卡），不是多欄平鋪
- Paywall 不是中斷，是「章節封面」—— 解鎖前 = 目錄，解鎖後 = 正文

## 4. Character Consistency Rules（IP 保護規則）

這是避免 AI 生成失控的護欄。

| 規則 | 為什麼 |
|---|---|
| 32 基礎形一次畫完、入庫，之後只能微調不能重畫 | IP 要累積，每次改會吃掉辨識度 |
| 所有 variant 使用**同一構圖比例**（例如 1:1.5，角色在下 2/3） | 切換 variant 時視覺不跳 |
| **角色線條粗細統一**、色塊層次統一（建議 3–5 色） | 是 V2 的簽名 |
| 臉部表情**克制**（微笑 / 沉思 / 平靜三種內） | 狀態由環境講，不由表情講。表情搶戲就破功 |
| 所有角色共用**同一光源方向** | 拼在一起不會打架 |

## 5. Composition Templates（版面構造）

三種構造循環使用。不是每頁都不同，是**三種節奏輪替**。

### Template α｜角色獨白
全螢幕：環境漸層 + 角色 + 一句話（三行內）
用在：封面、章節起首、心理原型頁

### Template β｜雙欄對映
左：角色縮圖 + 環境微縮
右：editorial 文字區塊（標題 + 引言 + 段落）
用在：正文大段落

### Template γ｜圖鑑卡
純資訊區塊（spectrum、tag、compare），**沒有角色**
用在：數據層、對照層

**規則**：α → β → γ → β → α 的節奏循環。不是每 section 都放角色。**角色稀缺才有份量**。

## 6. Motion Philosophy

V2 的動態詞彙：**呼吸、漂浮、微閃**。
禁用：彈跳、滑入、翻轉、fade-in 瀑布流。

- 呼吸：2–4 秒循環的透明度/scale 微變（粒子、光暈）
- 漂浮：隨機路徑慢速位移（粒子層）
- 微閃：偶爾的高光脈衝（點綴，不循環）

所有動態都是**循環的、無開始無結束**——因為狀態本來就是持續的，不是事件的。

---

## 7. Responsive / Breakpoint 策略

因為環境層是主敘事，不能在 mobile 上簡化掉。

- Desktop：角色約佔畫面 40–50% 高、環境滿版
- Tablet：比例不變，字體稍收
- Mobile：角色約佔 60% 寬，環境簡化為**單層漸層 + 低密度粒子**，取消光線品質層（省 GPU）

**Mobile 不是 desktop 的縮小版**。Mobile 是 reader mode、Desktop 是 cinema mode。
