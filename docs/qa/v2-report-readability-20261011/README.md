## 範圍與限制

文案從既有 Obsidian 正本生成，涵蓋 32 份報告與 128 個情境例子；保留原創第一人稱金句與甜點敘事。正文 16px、重要說明 14px、標註 12px；手機 A／T 上下排列，工作／關係單欄。
